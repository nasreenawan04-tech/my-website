## Course Overview

This comprehensive course teaches you how to make every page of any website fully SEO-friendly. You'll learn to optimize blogs, business sites, eCommerce stores, portfolios, and landing pages for maximum search engine visibility.

- On-Page SEO (meta tags, headings, keyword optimization, internal linking)

- Technical SEO (sitemaps, robots.txt, Core Web Vitals, structured data)
- Local SEO (Google My Business, location optimization)
- Content SEO (keyword research, content strategy, semantic SEO)
- AI SEO Tools & Automation (ChatGPT, SurferSEO, NeuronWriter)

### Prerequisites

- Basic understanding of websites and HTML (helpful but not required)
- Access to a computer and internet
- Willingness to learn and practice

- Submitting sitemaps to Google Search Console
- Sitemap best practices
- Image and video sitemaps

**Example XML Sitemap:**
```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://example.com/</loc>
    <lastmod>2025-01-10</lastmod>
    <changefreq>daily</changefreq>
    <priority>1.0</priority>
  </url>
  <url>
    <loc>https://example.com/blog/seo-guide</loc>
    <lastmod>2025-01-09</lastmod>
    <changefreq>weekly</changefreq>
    <priority>0.8</priority>
  </url>
</urlset>
```

- Robots.txt syntax and directives

**Example robots.txt:**
```
User-agent: *
Disallow: /admin/
Disallow: /private/
Disallow: /*?sort=
Allow: /

Sitemap: https://example.com/sitemap.xml
```

```html

</script>
```

### Lesson 10.3: Common SEO Issues and Fixes

**Issue 1: Duplicate Content**
- Problem: Same content on multiple URLs
- Detection: Screaming Frog, Google Search Console
- Fix: Canonical tags, 301 redirects, noindex

**Issue 2: Thin Content**
- Problem: Pages with little or no valuable content
- Detection: Manual review, content length analysis
- Fix: Expand content, consolidate pages, noindex

**Issue 3: Broken Links (404s)**
- Problem: Links pointing to non-existent pages
- Detection: Screaming Frog, Google Search Console
- Fix: Fix links, implement 301 redirects, create custom 404

**Issue 4: Slow Page Speed**
- Problem: Pages loading slowly
- Detection: PageSpeed Insights, GTmetrix
- Fix: Image optimization, minification, caching, CDN

**Issue 5: Missing Meta Tags**
- Problem: Pages without title/meta description
- Detection: Screaming Frog
- Fix: Add unique meta tags to all pages

**Issue 6: Orphan Pages**
- Problem: Pages with no internal links
- Detection: Screaming Frog
- Fix: Add internal links from relevant pages
